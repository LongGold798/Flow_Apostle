# Flow Apostle

Python 3.11+ 桌面监控器。通过 AKShare 读取新浪交易日历及东方财富实时轮询接口。事件按接收时间倒序展示，可按类型筛选。全部告警保存在 `data/events.sqlite3`，界面显示当日最近 800 条匹配记录。

## Windows 安装和启动

在本项目目录执行。建议使用独立虚拟环境，避免与 Anaconda 环境中已安装的二进制依赖冲突。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

北京时间交易日 09:30–11:30、13:00–15:00 轮询。运行 `main.py --probe` 可在休市时探测真实接口。休市接口可能返回最近交易时段快照或空池。网络失败自动退避，东方财富 push2 限流时同源请求暂停至少五分钟。看板保留最后收到的数据，结合顶部请求时间及状态判断新鲜度。

## 已实现规则

| 类型 | 所需数据与默认计算 |
| --- | --- |
| 个股快速上涨、快速下跌 | 沪深 A 股批量现价。15、30、60、180、300 秒窗口各自配置阈值。对比最近达到目标窗口的样本，实际跨度最多为配置的 1.5 倍 |
| 成交量、成交额放大 | 最短价格窗口内的累计成交增量除以实测秒数，分别对比该股此前 12 个非重叠采样间隔的速率中位数。默认达到 3 倍且窗口成交额增量至少 50 万元。基线是同交易时段内的历史采样 |
| 封涨停、炸板、回封、封跌停 | 东方财富盘中池。首次快照建立基线，后续入池和状态变更触发。连续封涨停快照之间炸板次数增加时，记录炸板后回封。池条目消失时无法确认具体变更 |
| 板块快速涨跌 | 东方财富行业、概念板块日涨跌幅在 60 秒窗口变化至少 0.8 个百分点 |
| 板块涨跌联动 | 60 秒内上涨或下跌家数增加至少 5 家，且反向家数没有增加。口径为板块涨跌家数，尚无逐成分股联动 |
| 板块资金异常与排行榜 | 东方财富「今日主力净流入-净额」。60 秒累计净额变化至少 3000 万元。行业与概念可分别查看正净额、负净额排名，同时显示能够匹配的涨跌幅和上涨、下跌家数 |

修改 `config.json` 后重启即可应用阈值、窗口和各接口频率。`disabled_events` 填写界面显示的事件名称。普通告警以对象、类型、窗口去重，默认冷却 90 秒。涨跌停状态变更独立记录。午休、跨日或过长的采样中断会重新预热。时间是程序收到批次的时间，快照实际更新频率和延迟由数据源决定。默认 15 秒窗口只有在采样频率足够时才会触发。

待补充的数据能力包括全市场实际涨跌停价与买卖盘口，因此临近、首次触价和跌停撬板尚未实现。板块榜当前缺板块成交额和涨停家数，普通个股告警尚无行业及概念归属。P1 的高低开、反弹回落、新高新低、换手率、个股资金、市场整体和普通盘口，以及 P2 逐笔和撤单仍待扩展。

## 验证

```powershell
.\.venv\Scripts\python.exe -m unittest -v
.\.venv\Scripts\python.exe main.py --probe
```

规则测试用固定输入覆盖价格窗口、冷却及断档、成交基线、涨停状态链、板块涨跌及资金、沪深范围和事件分发。2026-11-13 真实接口探测取得新浪交易日历 8797 条及涨跌停池 64 条。沪深行情、板块行情及板块资金接口触发东方财富限流。完整盘中端到端运行和最短采样周期仍需验证。

参考 [vn.py](https://github.com/vnpy/vnpy) 的事件队列及订阅方式、[OpenStock](https://github.com/Open-Dev-Society/OpenStock) 的行情与提醒展示，并使用 [AKShare 官方接口](https://akshare.akfamily.xyz/data/stock/stock.html)。
